# Shrimp Price Predictor

Regional monthly shrimp-price forecasting using **farm-gate shrimp prices**, export prices, weather, disease outbreaks, aquaculture production and macroeconomic variables.

## Price modes

The dashboard keeps two separate price targets:

### Farm-gate mode
Forecasts the raw shrimp price paid around harvest, before processing/export. The configured series is **Vannamei, 60 count/kg**. Only real farm-gate observations are used as the target; missing months are not filled with export prices.

### Export mode
Forecasts the export-market price using regional shrimp export unit values, with the IMF/FRED global shrimp benchmark as a fallback when a regional trade observation is unavailable.

## Data sources

- **Shrimp Insights Farm Gate Price portal:** farm-gate prices from major origins, with species and size categories.
- **IMF/FRED:** monthly global shrimp benchmark (`PSHRIUSDM`).
- **UN Comtrade:** monthly export unit-value proxy for frozen shrimp/prawns (HS 030617).
- **NASA POWER:** monthly temperature, precipitation, humidity and wind.
- **WOAH WAHIS / EcoHealth Alliance WAHISDB:** aquatic disease events and quantitative outbreak-impact records.
- **FAO FishStat:** shrimp aquaculture production by country/year.
- **FRED:** USD/INR, WTI crude oil and US CPI.

## Forecasting approach

The model works at monthly regional resolution. Features include:

- target-price lags and rolling averages
- export-market lag (used by the farm-gate model)
- temperature and rainfall history
- disease event count and outbreak impact
- shrimp aquaculture production
- USD/INR, crude oil and inflation
- month-of-year seasonality

Models are selected with leakage-safe expanding-window walk-forward validation.

## Farm-gate data ingestion

The public Shrimp Insights portal provides a **Download data** action. Because the site does not document a permanent API endpoint, the ingestion script accepts the downloaded file directly or a direct download URL.

Option A: place the portal export at `data/raw/farmgate/source.csv`.

Option B: set `SHRIMP_FARMGATE_URL` to a direct CSV/XLSX download URL and run the pipeline.

GitHub Actions also accepts the repository secret `SHRIMP_FARMGATE_URL`. The pipeline performs best-effort public discovery from the portal first, but a direct URL is the most reproducible approach.

## Run locally

`pip install -r requirements-v2.txt`
`python scripts/run_pipeline.py`
`python validation/walk_forward.py`
`uvicorn backend.main:app --reload`

Open the dashboard at `http://127.0.0.1:8000`.

## Reproducibility

Raw source downloads are intentionally ignored by Git. The processed master dataset is generated by the pipeline and refreshed through GitHub Actions.

## Full farm-gate dataset

The repository now keeps the complete downloaded farm-gate source at:
`data/farmgate/shrimp_insights_farmgate.csv`

No species or size is discarded. The dashboard exposes the available **country → species → size/count** combinations dynamically. The current downloaded file contains 5 country codes, 2 species and 18 observed size values across 22 weekly dates in 2026.

The farm-gate model is a pooled model: it learns across all available varieties while conditioning on country, species and size. It also incorporates weekly price lags plus monthly weather, disease, production, export-market, global shrimp and macro context when those datasets are available.

Because the current farm-gate download only covers a short 2026 window, the application explicitly warns that long-horizon farm-price estimates are not backed by a deep farm-gate history yet.
