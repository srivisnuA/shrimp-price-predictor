# Shrimp Price Predictor

Regional monthly shrimp-price forecasting using market prices, weather, disease outbreaks, aquaculture production and macroeconomic variables.

## What changed

The original prototype used a small hand-built yearly dataset. The new pipeline uses source-backed monthly data and keeps each source separate so the forecast is auditable.

### Data sources

- **IMF/FRED:** monthly global shrimp benchmark (FRED `PSHRIUSDM`).
- **UN Comtrade:** monthly export unit-value proxy for frozen shrimp/prawns (HS 030617).
- **NASA POWER:** monthly temperature, precipitation, humidity and wind for configured shrimp-producing regions.
- **WOAH WAHIS / EcoHealth Alliance WAHISDB:** aquatic disease events and quantitative outbreak-impact records.
- **FAO FishStat:** shrimp aquaculture production by country/year.
- **FRED:** USD/INR, WTI crude oil and US CPI as market/macro controls.

## Regions

Configured in `config/regions.json`:

- Andhra Pradesh, India
- Tamil Nadu, India
- Mekong Delta, Viet Nam
- Guayas, Ecuador
- Sumatra, Indonesia

## Forecasting approach

The model works at monthly regional resolution.

Features include:

- price lags and rolling price
- temperature and temperature history
- rainfall and rainfall history
- disease event count and lagged outbreak impact
- shrimp aquaculture production
- USD/INR
- crude oil
- inflation
- month-of-year seasonality

Candidate models:

- HistGradientBoostingRegressor
- GradientBoostingRegressor
- RandomForestRegressor

Models are selected with leakage-safe expanding-window walk-forward validation. Future weather, disease, production and macro variables can be supplied as scenarios; otherwise seasonal/historical values are used.

## Run locally

```bash
pip install -r requirements-v2.txt
python scripts/run_pipeline.py
python validation/walk_forward.py
uvicorn backend.main:app --reload
```

Open the dashboard at `http://127.0.0.1:8000`.

## Reproducibility

Raw source downloads are intentionally ignored by Git. The monthly processed master dataset is generated by the pipeline and refreshed through GitHub Actions.
