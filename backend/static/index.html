What the farm-gate model uses

Farm-gate forecasts use country, species, size/count, weekly price history, seasonal timing, weather, disease, production, export-market price, global shrimp benchmark and macro variables when those context datasets are available. The uploaded farm-gate source currently contains a short 2026 history, so the dashboard warns when longer-history evidence is unavailable.

Forecasts are statistical estimates, not trading or market advice.
